# 中文 UI 验收清单

## 通用
- [ ] 顶部导航、侧边菜单均为中文
- [ ] 按钮文案为中文：登录、退出、新增、保存、删除、恢复、搜索
- [ ] 表单标签、placeholder、校验提示均为中文
- [ ] 空态、加载态、错误态文案为中文
- [ ] tooltip/确认框为中文

## 登录页
- [ ] 用户名/密码标签中文
- [ ] 登录失败提示中文且易懂

## 文章页
- [ ] 列表列名中文
- [ ] 分页控件中文
- [ ] 删除/恢复操作提示中文
- [ ] 编辑器工具提示尽量中文；若第三方控件无法完全中文，需在文档注明

## 分类页
- [ ] 新增/编辑/删除分类相关文案中文
- [ ] 排序操作提示中文

## 搜索
- [ ] 搜索框 placeholder 中文
- [ ] “无结果”提示中文
- [ ] 高亮展示不破坏中文排版

## 上传
- [ ] 拖拽/粘贴说明中文
- [ ] 上传成功/失败提示中文
