# 测试与验收说明

## 覆盖范围
- 登录鉴权：登录/退出、未登录拦截、会话失效
- 文章管理：新增、编辑、详情、软删除、恢复、分页、排序、浏览量
- 分类管理：新增、编辑、删除、排序、按分类筛选
- 搜索：标题/内容全文检索、关键字高亮、空结果
- 上传：拖拽/粘贴上传、Markdown 自动插入、非法文件拦截
- 中文一致性：菜单、按钮、表单、错误提示、tooltip 全中文
- 安全边界：弱口令提示、鉴权绕过、XSS、上传类型限制、越权访问

## 执行建议
1. 先准备管理员账号、测试分类、测试文章、测试图片。
2. 先跑手工验收清单，再执行 E2E。
3. 若接口可直连，按下述用例补齐 API 自动化。

## API/页面测试用例
### 1. 登录鉴权
- 正常登录：正确账号密码 -> 进入后台首页。
- 错误密码：提示中文错误，不泄露账号是否存在。
- 未登录访问后台页：跳转登录页。
- 退出登录：会话失效，再访后台需重新登录。
- 会话过期：操作时提示重新登录。

### 2. 文章管理
- 新增文章：标题/分类/标签/Markdown 内容保存成功。
- 编辑文章：修改全部字段后列表与详情一致。
- 详情渲染：Markdown、代码高亮正常。
- 软删除：删除后前台不可见，后台可恢复。
- 恢复：恢复后重新出现在列表/搜索结果。
- 分页：每页 15 条，翻页正确。
- 排序：按最后更新时间倒序。
- 浏览量：访问详情后计数递增。

### 3. 分类管理
- 新增/编辑分类成功。
- 删除分类时关联文章处理符合预期。
- 分类自定义排序生效。
- 按分类筛选文章正确。

### 4. 搜索
- 标题命中/内容命中均可搜到。
- 结果中关键字高亮。
- 中文关键字可搜。
- 无结果时中文空态提示正确。
- 特殊字符搜索不报错。

### 5. 上传
- 拖拽上传成功并插入 Markdown 图片语法。
- 粘贴图片上传成功。
- 非图片文件被拒绝并提示中文错误。
- 超大文件限制提示明确。

### 6. 安全
- 未登录不能调用后台新增/编辑/删除。
- 输入 <script> 等内容时页面不执行恶意脚本。
- 上传脚本文件/伪装扩展名应拒绝。
- 搜索、筛选、分页参数异常时服务稳定。

## 通过标准
- P0 场景全部通过；无阻塞缺陷。
- 中文文案一致，无明显英文漏出。
- 安全边界无高危问题。
