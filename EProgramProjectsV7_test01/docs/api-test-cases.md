# API测试用例清单

## 鉴权
1. 正确账号密码登录成功，返回token/session
2. 错误密码登录失败
3. 未登录访问受保护接口返回401/403
4. 退出后token失效

## 文章CRUD
1. 创建文章：标题/内容/分类/标签合法
2. 创建失败：必填项缺失
3. 查询文章详情成功
4. 更新文章成功
5. 删除文章成功

## 搜索/分页
1. 关键词搜索命中标题/内容
2. 空关键词返回默认列表
3. page/size正常翻页
4. 超范围页码返回空列表或最后一页策略正确

## 分类/标签
1. 新增分类/标签成功
2. 重名创建失败
3. 编辑成功
4. 删除成功/关联数据删除限制正确

## 上传
1. 上传jpg/png成功并返回URL
2. 非法格式失败
3. 超大小失败
