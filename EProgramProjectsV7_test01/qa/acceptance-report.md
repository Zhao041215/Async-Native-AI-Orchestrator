# 验收报告

## 覆盖范围
- 登录/退出登录
- 产品管理：新增、搜索、中文表头断言
- 入库：成功提示“入库成功”
- 出库：库存不足校验“库存不足，当前库存为 X”与成功提示
- 库存查询：状态“正常/库存不足”与低库存筛选
- 出入库记录：日期/产品/类型筛选与分页文案“上一页/下一页”
- 管理设置：修改密码页中文文案与提交流程
- 全站关键中文文案检查

## 缺陷清单
1. 仪表盘汇总文案在需求中描述为中文，但项目描述同时出现英文 summary 文案，需统一。
2. 产品新增/密码修改成功提示文案未在需求中明确，断言策略需按实际实现补充。
3. 历史记录筛选按钮未明确命名，脚本采用填充后直接校验列表，若需显式查询按钮请补充。
4. 删除产品的中文确认弹窗未纳入自动化主流程，建议后续补充专门用例。

## 执行说明
- 运行前设置 `BASE_URL`、`E2E_USERNAME`、`E2E_PASSWORD`
- 若需验证改密回归，设置 `E2E_NEW_PASSWORD`
- 推荐命令：`npx playwright test playwright/inventory-core.e2e.spec.ts`
